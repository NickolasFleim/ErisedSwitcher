# Подпись кода и антивирусы

Erised Switcher перехватывает клавиатуру, печатает текст за пользователя и обновляет сам себя.
Так же ведут себя и вредоносные программы, поэтому неподписанный exe антивирусы и SmartScreen
встречают с подозрением. Что с этим делать — по порядку пользы.

## 1. Подпись кода (лучше всего)

Подписанный exe SmartScreen со временем перестаёт показывать как «неизвестный», а антивирусы
доверяют ему заметно больше.

**Бесплатно для открытых проектов — [SignPath Foundation](https://signpath.org/).**
Подаётся заявка на проект (нужны открытый код под OSI-лицензией — GPL-3.0 подходит, сборка в
GitHub Actions и страница проекта). После одобрения SignPath подписывает файлы, собранные в Actions.

**Свой сертификат** (покупается у центра сертификации; с 2023 года выдаётся на аппаратный ключ или
облачный сервис). Если у вас есть сертификат в виде файла `.pfx`, сборка релиза подпишет файлы сама:

1. Закодируйте файл: в PowerShell `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cert.pfx")) | Set-Clipboard`.
2. В репозитории: Settings → Secrets and variables → Actions → New repository secret:
   - `SIGN_PFX_BASE64` — вставленная строка;
   - `SIGN_PFX_PASSWORD` — пароль от `.pfx`.
3. Следующий тег `vX.Y.Z` соберётся уже подписанным (шаг «Подпись» в `.github/workflows/release.yml`).
   Без этих секретов шаг просто пропускается.

## 2. Если антивирус ругается на конкретную версию

- Проверьте файл на [VirusTotal](https://www.virustotal.com/) — видно, какие именно антивирусы срабатывают.
- **Microsoft Defender:** отправьте файл как ложное срабатывание —
  [Submit a file for malware analysis](https://www.microsoft.com/en-us/wdsi/filesubmission),
  тип «Software developer», вердикт «Incorrectly detected as malware». Обычно разбирают за 1–3 дня,
  после чего сигнатуры обновляются у всех.
- Остальные антивирусы принимают ложные срабатывания на своих сайтах (ссылки есть в отчёте VirusTotal).

## 3. Что уже сделано в программе

- В exe есть сведения о версии (издатель, описание, версия) и манифест — файлы без них выглядят подозрительнее.
- Программа ничего не скачивает и не запускает, кроме своих обновлений с GitHub, проверенных по SHA-256.
- Нет упаковщиков и обфускации; исходники открыты, сборка — в GitHub Actions по тегу.

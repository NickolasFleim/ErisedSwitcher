# Что нового

## 1.2.0

- Подсказки при наборе, как на телефоне: полоска с вариантами у курсора ввода (или у мыши, или внизу экрана).
- Исправление опечаток при пробеле с учётом соседних клавиш; Backspace сразу после исправления возвращает как было. Режим «Только подсказывать».
- Предсказание следующего слова по вашей истории набора (только известные слова, локально, без полей паролей).
- Принятие варианта: Tab, Ctrl+1/2/3, щелчок, стрелка вправо (по выбору); Esc скрывает полоску.
- Список из 630 тыс. русских и 540 тыс. английских форм слов, чтобы не «исправлять» правильные редкие слова.
- Новая вкладка «Подсказки» с историей набора; «Проверка» показывает исправления опечаток и подсказки.
- В терминалах и редакторах кода подсказки и исправление опечаток по умолчанию выключены.

## 1.1.0

- Программа называется Erised Switcher. Настройки и собранные слова из Smena переносятся сами, старая версия закрывается и убирается из автозапуска.
- Настройки открываются в отдельном окне программы (WebView2); запасной вариант — окно Edge без адресной строки.
- Двойной Shift конвертирует выделенный текст, если он выделен (мышью, Shift+стрелками, Ctrl+A), иначе — последнее слово; результат снова выделяется, повторное нажатие возвращает как было.
- Проверка конфликтов горячих клавиш.
- Значок программы, поддержка экранов с высоким DPI.
